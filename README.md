# HelpDesk TI

Sistema de abertura e gerenciamento de chamados técnicos para suporte de TI.

---

## Tecnologias

* **PHP 8+**
* **SQLite**
* **RedBeanPHP**
* **Pico.css v2**

---

## Pré-requisitos

* PHP 8.1 ou superior instalado
* Extensões ativas no `php.ini`: `pdo_sqlite` e `sqlite3`

---

## Como Executar

1. Clone o repositório:


```bash
git clone [https://github.com/LucasABX/projeto_estagio_2026_2.git](https://github.com/LucasABX/projeto_estagio_2026_2.git)
cd projeto_estagio_2026_2
```


2. Inicie o servidor embutido do PHP:

```bash
php -S localhost:8000 -t public
```

3. Acesse no navegador:
`http://localhost:8000`
